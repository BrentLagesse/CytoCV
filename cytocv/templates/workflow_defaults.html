Signal Quantification

Controls the primary Red/Green signal measurement workflow for this experiment. Choose one primary mode: Puncta Distance or Nuclear, Cell-Pair Intensity.

Requires: Red, Green.

Primary Mode selects which mutually exclusive signal workflow is saved as the default. The selected mode determines which statistics are calculated, which child controls are shown, and which results appear in the output.

{% if preferences.experiment_defaults.signal_quantification_enabled %}{% if preferences.experiment_defaults.signal_quantification_mode == 'nuclear_cell_pair' %}Nuclear, Cell-Pair Intensity primary mode on. Other stat modules disabled.{% else %}All other stat modules enabled in Puncta Distance mode.{% endif %}{% endif %}

Detects the first two usable puncta in the selected source channel, measures the distance between their centers, draws a line mask between them, and sums intensity from the opposite measurement channel along that line. Results include puncta distance, puncta line intensity, and pixel/scale-adjusted distance values.

Chooses which channel defines the two puncta and which opposite channel is measured. Red Puncta measures Green signal along the Red-puncta line; Green Puncta measures Red signal along the Green-puncta line.

Sets the thickness of the line mask used for the line-intensity sum. Values can be entered in pixels or microns; micron values are converted using the active measurement scale.

Optionally calculates raw intensity sums inside detected Red and Green contour masks. When enabled, results include Red in Red, Green in Red, Red in Green, Green in Green, Green-from-Red distance fields, and Measurement/Contour ratios for the selected puncta source.

Measures signal from the selected measurement channel inside the selected nucleus contour and inside the full DIC cell-pair mask. Results include nucleus contour channel, measurement channel, nuclear intensity, cell-pair intensity, cytoplasmic intensity, and nuclear status.

Chooses which channel supplies the nucleus contour and which opposite channel is measured. Green Nucleus uses the Green contour as the nucleus and measures Red signal; Red Nucleus uses the Red contour as the nucleus and measures Green signal.

Changes only the Nuclear, Cell-Pair nucleus contour path. When enabled, the alternate detection path is used for the selected nucleus source channel only: Red Nucleus uses alternate Red detection, and Green Nucleus uses alternate Green detection. If disabled, the standard nucleus contour path is used.

Balanced keeps the current alternate nucleus behavior. Aggressive uses tighter speckle-derived alternate nucleus masks for the selected nucleus source channel when Alternate Nucleus Detection is enabled.

Uses YeastAnalysisTool-style 8-bit scaled measurement pixels while preserving CytoCV channel identity, contours, nucleus clipping, and cell-pair masks.

Dot Detection

Splits connected multi-peak Red and/or Green signal into separate dot contours before statistics are calculated.

Requires: Red or Green.

Choose which dot contours get the post-contour merge fix.

Balanced uses standard split sensitivity, now stronger than the old balanced mode. Aggressive is the highest-recall split mode for tiny, very close, unequal, or tip-connected merged Green dots.

Balanced uses standard split sensitivity. Aggressive is the highest-recall split mode for tiny, very close, unequal, or tip-connected merged Red dots.

Experimental

Filters low-confidence Green signal contours in challenging images.

Experimental: behavior can vary across image quality, exposure, and channel mapping. Validate overlays before using results for conclusions.

Requires: Green.

Measurement Scale

When enabled, each file uses DV header dx/dy scale. If unavailable, workflow falls back to manual µm/px.

{% if preferences.experiment_defaults.use_metadata_scale %} Metadata mode enabled {% else %} Fallback-only mode enabled {% endif %}

Fallback manual scale used when metadata dx/dy is unavailable or invalid.

  • Enter µm/px (not px/µm).
  • Example: if 1 pixel = 0.1 µm, enter 0.1.

Pixels: pixels = micrometers / (µm/px)

Anisotropic Distance: distance in µm = sqrt((DeltaX_px * dx)^2 + (DeltaY_px * dy)^2)

Single-Width Proxy: proxy µm/px = sqrt(dx * dy)

Sets the default px or µm view used when display and dashboard first render. Page-level toggles can still override each file without changing this workflow default.
